# Browser

***Embed any webpage directly on your signage display — dashboards, portals, live feeds, web apps.***

Turn any URL into full-screen signage content. The Browser applet renders a live webpage on your display with native browser support, keeping the content interactive and auto-refreshing as the source updates. No iframes, no workarounds — just point it at a URL and it fills the screen.

Works across all signageOS-supported devices with consistent rendering behavior regardless of the underlying hardware platform.

## Highlights

- **Full-screen web rendering** — any publicly accessible URL displayed edge-to-edge
- **Live and interactive** — the page stays active, auto-refreshing with source updates
- **Native browser engine** — uses the device's built-in browser for optimal performance
- **Universal compatibility** — runs on all signageOS-supported hardware

## Use Cases

- KPI dashboards and real-time analytics (Grafana, Looker, Power BI)
- Internal company portals and intranet pages
- Social media walls and live feeds
- Third-party web applications and booking systems
- Web-based CMS-powered menu boards

## Getting Started

Install from the Marketplace, assign to a device, and the applet loads the configured URL full-screen. The page runs continuously with no manual intervention.
