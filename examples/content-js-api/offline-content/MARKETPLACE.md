# Offline Content

***Cache data on the device so your screens keep running — even without internet.***

Network outages happen. The Offline Content applet demonstrates how to use the signageOS Offline Cache API to store content directly on the device. Once cached, your screens continue displaying without interruption regardless of connectivity — no buffering, no blank screens, no downtime.

Content syncs automatically when the network is restored, keeping everything up to date without manual intervention.

## Highlights

- **On-device storage** — content served from local cache, not the network
- **Network-resilient** — screens stay running during connectivity drops
- **Automatic sync** — updates pull through when the connection is back
- **Universal compatibility** — works on all signageOS-supported devices

## Use Cases

- Outdoor and transit signage with unreliable connectivity
- Retail locations with spotty or congested WiFi
- Mission-critical displays that cannot afford downtime
- Kiosks and remote deployments with intermittent internet

## Getting Started

Install from the Marketplace, assign to a device, and configure the content URLs. The applet downloads and caches everything locally, then serves content from device storage around the clock.
