# Brightness Control

***Programmatic display brightness management using the signageOS Screen API.***

Control your display's brightness without touching a remote. The Brightness Control applet provides an interactive interface to read and set screen brightness levels using the signageOS Screen API — useful for testing brightness behavior, validating policies, or one-off adjustments during deployment.

## Highlights

- **Read and set brightness** — get current level and apply new values via Screen API
- **Interactive controls** — on-screen buttons for quick brightness adjustments
- **API demonstration** — reference implementation for the signageOS Screen API
- **Universal compatibility** — works on all devices with brightness control support

## Use Cases

- Testing brightness behavior on new hardware
- Validating brightness policies before fleet-wide rollout
- Quick manual adjustments during device installation
- Reference for developers integrating the Screen API

## Getting Started

Install from the Marketplace and assign to a device. Use the on-screen controls to read the current brightness and set new values. No configuration required.
