# Clock

***A clean digital clock widget for standalone displays or multi-zone layouts.***

Drop a reliable time display onto any screen in seconds. The Clock applet shows the current time with zero configuration — it just works. Use it as a full-screen clock or embed it as a widget in a multi-zone signage layout alongside other content.

Lightweight and resource-efficient, it runs smoothly even on low-powered signage hardware without impacting other applets in your layout.

## Highlights

- **Zero-config deployment** — starts showing time immediately after install
- **Layout-friendly** — works standalone or as a widget in multi-zone setups
- **Minimal footprint** — negligible CPU and memory usage
- **Universal compatibility** — runs on all signageOS-supported devices

## Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `standUpTime` | string | `10:30` | Time of day (HH:MM) to display a "stand up" reminder |

## Use Cases

- Lobby and reception area time displays
- Corporate information screens
- Waiting rooms and public spaces
- Time widget in multi-zone digital signage layouts

## Getting Started

Install from the Marketplace and assign to a device. The clock appears immediately — no setup required. Optionally set `standUpTime` to add a daily reminder notification.
