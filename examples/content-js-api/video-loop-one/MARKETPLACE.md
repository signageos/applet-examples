# Single Video Loop

***Cache one video on the device and loop it continuously — reliable 24/7 playback, even offline.***

The simplest video signage setup: one video, one screen, playing on repeat. The applet downloads the video to device storage and loops it with seamless restarts — no flicker, no loading spinner, no network dependency after the initial cache. Set it and forget it.

## Highlights

- **Single-video focus** — optimized for one video on continuous repeat
- **On-device caching** — downloads once, plays from local storage
- **Seamless looping** — no visible gap or flash between loops
- **Fully offline** — plays independently of network after initial download

## Use Cases

- Brand and promotional video displays
- Safety and compliance message screens
- Welcome screens in lobbies and entrances
- Point-of-sale promotional loops
- Ambient content in restaurants, hotels, and spas

## Getting Started

Install from the Marketplace and assign to a device. The applet caches the video locally and starts looping. No configuration required — uses a built-in demo video by default.
