# React Starter Template

***Boilerplate for building signageOS applets with React — pre-configured and ready to deploy.***

Skip the setup and start building. This template comes with the signageOS SDK already integrated, the build pipeline configured, and the project structure following CLI conventions. Add your React components, use the signageOS device APIs, and deploy to your fleet with standard CLI commands.

Intended as a starting point — fork it, extend it, make it yours.

## Highlights

- **Pre-configured build** — signageOS SDK wired in, ready to compile and upload
- **Standard project structure** — follows signageOS CLI conventions
- **React + signageOS SDK** — full access to device APIs from React components
- **Extensible** — add routing, state management, or any React library

## Use Cases

- Developers starting a new signageOS applet with React
- Teams standardizing on React for their signage content
- Rapid prototyping of interactive signage experiences
- Learning how signageOS integrates with modern frontend frameworks

## Getting Started

Install from the Marketplace or clone the repository. The project is ready to build — run `sos applet upload` to deploy. Add your components, use `sos.config` for runtime parameters, and iterate.
