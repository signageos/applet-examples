# Video Offline Playback Playlist

Loops through a playlist of videos with offline caching for reliable gapless playback. Videos are downloaded and cached on the device before playback begins.

## Configuration

The applet accepts an optional configuration parameter via `sos.config`:

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `items` | string | No | Comma-separated list of video URLs to play. Falls back to built-in demo videos if not provided. |

### Example

```
items: https://example.com/video1.mp4, https://example.com/video2.mp4, https://example.com/video3.mp4
```

## How It Works

1. Reads video URLs from `sos.config.items` (or uses defaults)
2. Downloads and caches all videos to device offline storage
3. Plays videos in a continuous loop with gapless transitions
4. Pre-buffers the next video while the current one is playing
